# game-design-knowledge

Agent Skill для геймдизайна игры любого жанра и масштаба: экшен и шутеры, RPG, стратегии, платформеры, головоломки, гонки и спорт, рогалики, карточные и настольные, MMO, мобильные, VR. Концепт и опоры, прототипы, документация для людей и ИИ-агентов, системный дизайн и баланс, экономика, уровни, интерфейс, процедурная генерация, плейтесты и метрики, симуляция баланса ботами, ревью дизайна и архитектура кода игры.

Скилл даёт ИИ-агенту (Claude Code, claude.ai и другим инструментам с поддержкой формата [Agent Skills](https://agentskills.io)) четыре вещи:

- **библиотеку знаний** — сотни ссылок на книги, статьи, доклады GDC, исследования и разборы игр по категориям. У каждой ссылки есть автор, год и пояснение, зачем её читать. Главная таблица — «симптом → решение → источник» для типичных проблем дизайна во всех жанрах: доминирующий персонаж или стратегия, стена сложности, снежный ком, перекос сторон, гринд, инфляция, непонятный интерфейс и другие;
- **шаблоны** — one-sheet с опорами, спецификация фичи для программиста и ИИ-агента, бриф прототипа, план плейтеста, журнал дизайна, стартовые целевые коридоры метрик для разных типов игр;
- **скрипты** — сводка логов симуляций, телеметрии и плейтестов в метрики с доверительными интервалами, сравнение с базовой линией по коридорам, расчёт выборки, равновесие меты, кривая стоимости, вероятности колод и пулов, два учебных стенда;
- **пайплайн** — опрос, концепт и целевые метрики, прототип, спецификация, тесты правил, измерительный стенд, базовый замер, ревью кода и дизайна, поиск решений в библиотеке, изменения и повторный замер. Правка принимается, только если целевая метрика приблизилась к коридору, а остальные не ухудшились.

Состояние знаний — октябрь 2026. Тексты справочников на русском, названия источников — в оригинале.

## Состав

```text
game-design-knowledge/
├── SKILL.md                     точка входа: куда смотреть и как работать
├── references/
│   ├── pipeline.md              пайплайн с циклом замеров, схемы стенда, учебные прогоны
│   ├── mechanics-patterns.md    паттерны механики и таблица «симптом → решение → источник»
│   ├── foundations.md           фреймворки: MDA, линзы, петли, мотивация, game feel
│   ├── systems-balance.md       баланс, боевая математика, вероятности, сложность, экономика, ориентиры
│   ├── playtesting-metrics.md   плейтесты, метрики по типам игр, симуляции ботами, статистика
│   ├── design-review.md         ревью дизайна: эвристики, обучение, доступность, чеклисты по типам игр
│   ├── ux-ui.md                 интерфейс: HUD, читаемость, меню, ввод, локализация, UI по жанрам
│   ├── procedural-generation.md процедурная генерация и оценка генераторов
│   ├── ai-assisted-design.md    LLM-агенты, персоны, генерация контента, ИИ в разработке
│   ├── documentation.md         one-sheet, GDD, спецификации для агентов, прототипы, продакшн
│   ├── architecture-code.md     системы геймплея, движок правил, data-driven, детерминизм, ИИ, тесты
│   ├── genres.md                особенности жанров: от шутеров и RPG до рогаликов, гонок и VR
│   └── books.md                 книги, курсы, каналы и маршрут чтения
├── assets/                      шаблоны документов и targets/ — коридоры по типам игр
└── scripts/
    ├── design_metrics.py        JSONL → метрики
    ├── metrics_compare.py       базовая линия против повторного замера и коридоров
    ├── sample_size.py           сколько матчей, забегов или игроков нужно
    ├── meta_equilibrium.py      равновесие меты по матрице матчапов
    ├── cost_curve.py            кривая стоимости и объекты вне кривой
    ├── deck_odds.py             вероятности колод, мешков и пулов
    ├── example_runs_sim.py      учебный стенд: забеги рогалика
    └── example_sim.py           учебный стенд: дуэль 1×1
```

Агент загружает `SKILL.md`, когда задача касается геймдизайна. Справочники он открывает только тогда, когда нужен конкретный раздел, поэтому скилл почти не занимает контекст, пока не используется.

## Установка

**Claude Code: для всех проектов**

```bash
git clone https://github.com/Betreazen/game-design-knowledge-skill.git
cp -r game-design-knowledge-skill/game-design-knowledge ~/.claude/skills/
```

**Claude Code: для одного проекта.** Скопируйте папку `game-design-knowledge` в `.claude/skills/` в корне проекта и закоммитьте её.

**claude.ai.** Заархивируйте папку `game-design-knowledge` в zip и загрузите в разделе Skills настроек claude.ai. Во frontmatter только стандартные поля `name` и `description`.

**Другие агенты (Codex, Gemini CLI, GitHub Copilot, Cursor).** Скопируйте папку в `.agents/skills/` проекта.

Скриптам нужен Python 3.10+ без сторонних пакетов.

## Использование

Скилл срабатывает сам, когда задача касается геймдизайна. В Claude Code его можно вызвать и явно командой `/game-design-knowledge`.

Примеры запросов:

- «Составь one-sheet и опоры для моей игры и предложи целевые коридоры метрик»
- «Один герой выигрывает 58% матчей, а на атакующей стороне карты побеждают в 60%. Что можно сделать?»
- «Игроки массово бросают на третьем уровне. Как найти причину и что проверить?»
- «Напиши спецификацию системы способностей для агента-программиста с примерами правил»
- «Сделай стенд: безголовая симуляция боя или экономики, боты, лог в JSONL»
- «Сравни метрики до и после патча и скажи, принимать ли правку»
- «Проведи ревью интерфейса и обучения по эвристикам и чеклисту доступности»
- «Что почитать системному или левел-дизайнеру?»

Свой стенд пишет одну строку JSONL на единицу наблюдения (игрок в матче, забег, попытка уровня, симулированный день), а скрипты считают метрики:

```bash
python3 game-design-knowledge/scripts/design_metrics.py runs.jsonl --rate win --num duration_s \
  --by side --by pick --out metrics/before.json
python3 game-design-knowledge/scripts/metrics_compare.py metrics/before.json metrics/after.json \
  --targets design/targets.json
```

Попробовать весь цикл за минуту можно на учебных стендах: раздел «Учебный прогон» в `references/pipeline.md`.

## Пометки в справочниках

- `[устарело]` — у материала есть замена, и она указана рядом.
- `[не проверено]` — ссылку или факт не удалось подтвердить по первоисточнику; его стоит перепроверить.

Числовые ориентиры и стартовые коридоры — отправная точка для своих коридоров, а не отраслевой стандарт.
