## Правила

Нумерованные и атомарные. Одно правило — одно утверждение в шаблоне EARS.

- **R1.** When <событие>, игра <реакция>.
  - **R1.a.** If <крайний случай>, then <реакция>.
- **R2.** While <состояние>, <поведение>.
- **R3.** Where <вариант правил включён>, <поведение>.

Термины — только из глоссария правил (`design/rules/`). Новый термин сначала добавляется в глоссарий.

## Примеры

Каждый пример ссылается на правило и становится тестом.

```gherkin
Rule: R1

    Then <ожидаемое состояние и события>

  Example: <крайний случай: ноль здоровья / одновременные события / пустой инвентарь / граница уровня / ничья>
    Given ...

    Then ...
```
